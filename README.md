# 📖 주한태(Ju Han-tae) - 나에 대한 3만 자 장편소설 & 인터랙티브 웹 뷰어 (과제 11)

   - **설정 충돌 및 문단 중복 검사 결과 (`T11-C19`, `T11-C26~C30`)**:

   - 카드 안쪽 좌우 여백에 배치되어 마우스 호버 시 글래스모피즘과 네온 발광으로 반응하는 스타일리쉬 화살표 네비게이션
